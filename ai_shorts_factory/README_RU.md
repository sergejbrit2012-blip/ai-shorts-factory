# AI Shorts Factory — версия без Gemini и без API для сценариев

Проект собирает русскоязычные вертикальные Shorts из встроенной библиотеки тем: формирует короткий объясняющий текст, рисует собственные графические сцены, озвучивает их офлайн-движком eSpeak NG, собирает MP4 через FFmpeg и при настройке загружает на YouTube через официальный YouTube Data API.

**Важно:** в этой версии нет генеративной нейросети для сценариев. Сценарии создаются из шаблонов и редакционной библиотеки тем, поэтому они проще и могут повторяться. Это бесплатный режим без Gemini, GigaChat и платного генератора видео. Озвучка eSpeak NG синтетическая и звучит роботизированно.

## Что понадобится

1. GitHub — для облачных запусков GitHub Actions.
2. Google Cloud проект с включённым YouTube Data API v3 и OAuth Desktop credentials — только для загрузки на канал.
3. Компьютер Windows на несколько минут для первоначальной OAuth-авторизации.

## Локальная проверка на Windows

Установите Python 3.11+, FFmpeg и eSpeak NG (с русским голосом). Затем в папке проекта выполните:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Скачайте OAuth Desktop JSON из Google Cloud, сохраните как `client_secret.json` в корне проекта и запустите:

```powershell
python setup_youtube_auth.py
```

В браузере выберите свой YouTube-канал и разрешите загрузку видео. Появится `token.json`. Не публикуйте этот файл и никому его не отправляйте.

Для проверки создания ролика без загрузки выполните `python src/generate.py`. Для загрузки локально задайте `UPLOAD_TO_YOUTUBE=true` и `YOUTUBE_PRIVACY=private`.

## Развёртывание на GitHub Actions

1. Создайте публичный репозиторий GitHub и загрузите в него содержимое архива. Не добавляйте `token.json`, `client_secret.json` или `.env`.
2. Откройте Settings → Secrets and variables → Actions → New repository secret.
3. Создайте секрет `YOUTUBE_TOKEN_JSON` и вставьте полное содержимое локального `token.json`.
4. В Settings → Actions → General разрешите запуск GitHub Actions.
5. Откройте Actions → AI Shorts Factory → Run workflow для теста.
6. По умолчанию публикация закрытая (`private`). Проверяйте каждый ролик. Только после проверки меняйте переменную `YOUTUBE_PRIVACY` на `public`.

GitHub Actions запускает один ролик за запуск: ежедневно в 07:00, 10:00, 13:00, 16:00 и 19:00 UTC. GitHub может задерживать scheduled jobs. Это не гарантированный точный таймер.

## Как работает

- Темы берутся из `topics.txt`; можно добавлять свои темы.
- Сценарий составляется из встроенных текстовых блоков, без внешнего AI API.
- eSpeak NG синтезирует русскую речь локально на runner.
- Pillow рисует карточки 1080×1920, FFmpeg собирает видео.
- YouTube Data API загружает видео при включённой настройке.

## Ограничения и безопасность

- Это не полноценная AI-генерация: уникальность и разнообразие ограничены библиотекой тем и шаблонами. Для качественного канала лучше вручную проверять и улучшать сценарии, а не публиковать все пять автоматически без контроля.
- Визуал — графические карточки, не реалистичные видеосцены.
- eSpeak NG звучит механически.
- Для загрузки на YouTube всё равно нужен OAuth через Google Cloud; Gemini или Sber ID не нужны. Никогда не присылайте пароли, `token.json`, `client_secret.json` или ключи в чат.
- Сначала оставьте приватный режим и проверьте тестовый ролик.
